# 04 — IMU QMI8658

**Goal:** drain a 100 Hz FIFO on GPIO6, publish `q_device_to_world` + gravity + jerk. No magnetometer. No AttitudeEngine. No vendor HAL required.

## PDFs

Read **A** for programming. Use **C** only if `WHO_AM_I` on the board matches C.

| File | Role |
| :--- | :--- |
| [`../imu/QMI8658A_Datasheet_Rev_A.pdf`](../imu/QMI8658A_Datasheet_Rev_A.pdf) | **Primary.** Register map, FIFO watermark, INT, I2C 0x6A/0x6B, ODR/FS |
| [`../imu/QMI8658C_datasheet_rev_0.9.pdf`](../imu/QMI8658C_datasheet_rev_0.9.pdf) | Same family; confirm marking |

Bus: I2C 41/42. INT: GPIO6.

## What this chip can and cannot do

| Can | Cannot |
| :--- | :--- |
| 3-axis accel → gravity (pitch/roll) | Heading around gravity (no mag) |
| 3-axis gyro → smooth tilt, short-term yaw | Stable yaw while spinning on the table |
| FIFO + watermark INT | Replace your complementary filter |

Shake (`jerk`) is **not** fed into the camera. High-pass `|a|` → flinch on Core 0.

Skip in the datasheet: I3C, SPI-UI, external mag as I2C master, AttitudeEngine / XKF3 9D, self-test beyond a bring-up sanity check.

## Registers you implement

Addresses from the A datasheet UI map (confirm against the PDF while you code — do not memorize from a blog).

| Name | Typical addr | Point |
| :--- | :--- | :--- |
| `WHO_AM_I` | `0x00` | Probe. Log the value; pick A vs C init if they differ |
| `CTRL1` | `0x02` | SPI/I2C, INT pin enable, address |
| `CTRL2` | `0x03` | Accel ODR, full-scale, self-test |
| `CTRL3` | `0x04` | Gyro ODR, full-scale |
| `CTRL5` | `0x06` | LPF |
| `CTRL7` | `0x08` | Enable accel / gyro |
| `CTRL8` | `0x09` | Motion (you want raw IMU, not a vendor gesture) |
| `CTRL9` | `0x0A` | Host commands (soft reset, FIFO on) |
| `FIFO_WTM_TH` | `0x13` | Watermark in ODR counts |
| `FIFO_CTRL` | `0x14` | FIFO mode |
| `FIFO_SMPL_CNT` | `0x15` | How many to drain |
| `FIFO_STATUS` | `0x16` | Overflow |
| `FIFO_DATA` | `0x17` | Burst read |

I2C address: SA0 high/float → **0x6A**, SA0 low → **0x6B**. Read the schematic; then `WHO_AM_I`.

Suggested start: accel ±4 g or ±8 g (headroom for shake), gyro ±512 dps or ±1024 dps (fast table spin), ODR 100–250 Hz into FIFO, watermark so you wake ~100 Hz.

## Driver shape

Core 0, prio 12:

1. GPIO6 falling (or whatever the datasheet maps) → drain FIFO. Do **not** do this by polling in a 1 ms busy loop.
2. Convert raw → SI (datasheet sensitivity).
3. Run the complementary filter (guide 05).
4. Publish into the seqlock: `q_*`, `grav_*`, `jerk`.

**One I2C owner.** ES8311 register writes only on play start/stop/volume — never inside this drain.

Axis mapping is **bring-up**, not datasheet gospel. You will print `grav` while holding the board:

- Screen-up, sitting on the table → gravity along device −Z or +Z (pick, then lock).
- Tilt top edge toward you → pitch the boom camera, **not** the pet.

`architecture.md` uses `forward = rotate(q, {0,0,-1})` “into the screen; confirm on bring-up.”

## What not to copy

Waveshare `03_qmi8658_example` / SensorLib: fine for register poke order. Throw away their polling-from-loop and any Euler UI.

## Bring-up test (step 4)

USB print: ax ay az gx gy gz at 100 Hz. Magnitude of accel ≈ 1 g at rest. FIFO overflow count stays 0. INT rate ≈ 100 Hz. Then go to guide 05 and draw the cube.
